📌 Even or Odd Checker

The Even or Odd Checker is a simple beginner-friendly Python program that determines whether a given number is even or odd.
This project is designed to help new programmers understand user input handling, conditional statements (if-else), and basic 
arithmetic operations in Python. It is suitable for students, programming beginners, and academic practice, and can be used as 
a starter project for learning Python fundamentals.
